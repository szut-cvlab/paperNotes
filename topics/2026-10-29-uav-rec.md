# 无人机 REC / 视觉定位（UAV Referring Expression Comprehension）调研

> 调研日期 2026-10-29 | 覆盖 2022-2026 核心工作 
---

## 1. 问题定义与背景

**任务谱系**：**Visual Grounding（视觉定位）是总称**——把文本/短语链接到图像区域；REC 与 RES 是其两个子任务，区别仅在**输出形态**：
- **REC（Referring Expression Comprehension，指代表达理解）**：给定**一条完整**指代表达式 → 输出 **bounding box（框）**。本调研主体。
- **RES（Referring Expression Segmentation，指代表达式分割）**：同一条表达式 → 输出 **分割掩码（mask）**（如 Aerial-D、RefSegRS）。
- **Phrase Grounding（短语定位）**：给定**一句话/caption**，把里面每个短语分别 grounding 到框（输入是整句分散短语，而非一条明确指代）。
- **别名对照（下文统一用 REC/RES）**：VG（Visual Grounding/视觉定位）是总称，文献中常直接指代"输出框"的子任务，即 **REC**；RES 也称 Referring Image Segmentation（**RIS**/指代图像分割，输出掩码）。口语"指代检测"≈REC、"指代分割"≈RES——只是命名习惯差异（如 AerialVG 称 VG、RefDrone 称 REC，实则同一框定位任务）。

**与开放集检测的区别**：REC 的查询是**自由文本**而非类别名列表，要求模型理解"属性+关系+方位"的组合语义；且一条表达式可能匹配**多个**框或无匹配（无目标），而检测按类别输出固定框集。

**无人机 REC 四大挑战**：
1. **视角**：俯视/斜视，目标外观与自然图像截然不同
2. **小目标密集**：31% 目标 <32² px；文本描述依赖颜色/方位/交互而非纹理（RefDrone 发现颜色出现在 69% 表达式）
3. **多目标/无目标**：一条表达式可能指 0–242 个目标，或图中根本没有该对象（no-target）
4. **复杂环境上下文**：物体-物体、物体-环境交互推理（"载牲畜的白卡车""路口排队的白车"）

> 证据：RefDrone 零样本评测 26 个模型在无人机域全线崩溃，最强 LVLM 也仅 58.79 F1inst（RefCOCO 上 92%+）——通用域预训练跨不过域差异。

与地面 REC 基准（RefCOCO 系：单目标、大目标、无方位依赖）相比，航拍 REC 把上述假设全部打破。

## 2. 相关工作

### 2.1 REC 数据集（输出 bounding box）

- **RefCOCO / RefCOCO+ / gRefCOCO**（ECCV 2016 / CVPR 2017）：COCO 地面视角 REC 奠基基准，单目标、大目标、无方位依赖，是 REC 方法的主训练/评测集（非无人机）。
- **RSVG**（TGRS 2023）：首个遥感视觉定位数据集，基于 DIOR（Google Earth 遥感），17,402 图 / 38,320 图文对，模板化表达式、单目标空间关系，无多目标/无目标。
- **AerialVG**（ICCV 2025）：基于 VisDrone2019 的航拍视觉定位，5,000 图 / ~50,000 表达式 / 103,000 目标，强调 8 方向位置关系；单源（同 RefDrone 父集）。
- **RefDrone**（CVPR Findings 2026）：首个无人机 REC 基准，VisDrone2019，8,536 图 / 17,900 式 / 63,679 目标（留出 test 3,432 式 / 1,595 图），覆盖多目标/无目标+小目标；评测采用 **instance/image 双粒度**（IoU≥0.5，无目标样本无预测记 TN）
- **SkyFind**（TPAMI 2026）：首个大规模 UAV-based REC，35,599 图 / 1,015,638 对 / 352,910 物体，跨多样场景；test 聚合多源海事数据集制造分布偏移；基线 AerialREC。

### 2.2 RES 数据集（输出分割掩码）

- **Aerial-D**（arXiv 2512.07338）：多域航拍指代分割，1.5M+ 表达式 / 37,288 patches / 259K+ 目标 / 21 类，覆盖无人机/卫星/历史航拍。
- **RefSegRS**：遥感指代分割数据集（遥感版 RefSeg）。
- **RefDIOR**：基于 DIOR 的遥感指代分割数据集。
- **OPT-RSV**：光学遥感指代分割/视觉定位数据集。
- **VoiceAeroRef / AeroReformer2**：音频引导的航拍指代分割（语音 query）。

### 2.3 代表性方法（REC/RES 统一）

- **RECS4R**（CVPR 2026，西电）：方法论文——把 REC（输出框）与 RES（输出掩码）统一为"解码一串语言条件下的多边形轮廓顶点"：**框 = 这些顶点的外接矩形，掩码 = 这些顶点围成的多边形填充区域**，故框和掩码是同一轮廓的两个几何视图，用单个解码器取代"框头+掩码头"双头，REC 偏几何、RES 偏语义，优化目标不统一导致表征方向冲突，统一成轮廓后两种输出共享同一表征；叠加残差由粗到细编码、通道隔离多尺度融合、梯度域边界监督，在 RefDIOR / RRSIS-D / RefCOCO 系等 6 个数据集各刷 SOTA，拿 PolyFormer-Large 当对比基线、并超越它。它的卖点是把这个统一框架搬到遥感域。

## 3. 未来方向

1. **无人机 REC 跨域泛化**：RefDrone / AerialVG 均单源 VisDrone2019，SkyFind（TPAMI 2026）已用 1M+ 对 + 多源 test 抢占"广覆盖多源 REC 基准"空白——再做"更大/更多源无人机 REC 数据集"已无新颖性。应转向：① 跨采集条件泛化分析（哪些挑战是 drone REC 固有的、哪些是 VisDrone/单一源伪影）；② 域鲁棒 REC 方法。
2. **时序/视频 UAV REC**：RefDrone / AerialVG / SkyFind 均图像级，时序无人机 REC 是空白。
3. **RGB+IR / 多模态 UAV REC**（夜间/低光）：现有基准均未覆盖。
