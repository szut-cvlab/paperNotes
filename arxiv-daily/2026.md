### 1. [VGTok: Variable-Granularity Tokenization for High-Resolution Object Detection](https://arxiv.org/abs/2608.28706)
- **作者**: Khayrul Islam
- **关键词**: object detection, detr, high-resolution, aerial detection, tokenization
- **推荐度**: ⭐值得深入
- **推荐理由**: 高分辨率（航拍）目标检测的可变粒度 tokenization。针对 ViT 检测器固定 token 网格的问题，用免训练的 VGTok 按区域自适应粒度，在 VisDrone/AI-TOD-v2 上刷新 SOTA，且省 3.1 倍编码器算力。与猴哥的小目标/高分辨率检测兴趣直接相关，代码开源。
> 提出 VGTok，免训练的变量粒度 tokenizer，把 ViT 检测器的固定 token 网格改为按区域自适应。基于多尺度形态学顶帽可分离性打分 + 结构张量门控，在冻结 checkpoint 上直接 drop-in。Co-DETR + EVA-02 ViT-L 下在 VisDrone-val 全预算刷新 SOTA（40% token 即 44.22 AP），AI-TOD-v2 上 37.27 AP 新 SOTA，且省 3.1 倍编码器算力。代码开源。
