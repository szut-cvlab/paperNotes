- **关键词**: object detection, open-vocabulary, distillation, aerial detection
- **推荐度**: ⭐值得深入

### 3. [Calibrating Probabilistic Object Detectors with Annotator Disagreement](https://arxiv.org/abs/2605.24722)

### 5. [TinyFormer: Preserving Tiny Objects in YOLO-DETR Hybrid Real-time Detectors](https://arxiv.org/abs/2605.25046)
- **作者**: Jun-Wei Hsieh 等
- **关键词**: yolo, detr, tiny object detection, real-time
- **推荐度**: ⭐值得深入
- **推荐理由**: YOLO-DETR 混合架构解决小目标检测，SOTA 性能（58.4% AP small objects）。PBM 模块和 SSA 设计针对性强。
> 摘要：TinyFormer 统一 YOLO 和 DETR 混合实时检测器，提出 PBM 保持高分辨率特征，SSA 补偿 token 化带来的空间损失。

### 6. [Weakly Supervised Camouflaged Object Detection Based on SAM Model and Mask Guidance](https://arxiv.org/abs/2605.25385)

> 摘要：提出 MGNet 和 BoxSAM，用 SAM 结合边界框提示生成高质量 pseudo labels 进行弱监督训练。

### 7. [SAM3-Assisted Training of Lightweight YOLO Models for Precision Pig Farming](https://arxiv.org/abs/2605.25860)

- **关键词**: yolo, sam, precision agriculture
